# CNgirl — portada aprobada

Esta versión utiliza **la misma imagen aprobada**, sin volver a generarla. El banner original se recorta únicamente para separar la cabecera y los filtros, que deben ser funcionales. La composición del leopardo, el texto y la muñeca no se ha redibujado.

## Subir a GitHub
1. Descomprime el ZIP.
2. En tu repositorio `cngirl`, pulsa **Add file → Upload files**.
3. Arrastra **todos los archivos y carpetas interiores** (incluidas `assets` y `data`) y pulsa **Commit changes**.
4. Espera a GitHub Pages y recarga con Ctrl+F5.

La lista de productos está vacía a propósito. El panel de administración se configurará después.

Nota: En móviles la portada puede desplazarse horizontalmente para no recortar el texto ni la muñeca.
