# CNgirl — diseño de referencia 🐆

Esta versión utiliza **la imagen que elegiste** como portada decorativa (recortada a la zona del banner). Así la estética se acerca mucho al modelo aprobado, incluyendo muñeca, leopardo y tipografía cromada. El resto de la web (filtros, marcas y productos) funciona con HTML, CSS y JavaScript.

## Cómo actualizar tu web

1. Descomprime el ZIP.
2. Abre tu repositorio `cngirl` en GitHub.
3. Pulsa `Add file` → `Upload files`.
4. Arrastra **todos** los archivos y carpetas descomprimidos (incluyendo `assets` y `data`).
5. Pulsa `Commit changes` y espera unos minutos.
6. Recarga la web con Ctrl+F5.

No borres el repositorio. Los datos de productos empiezan vacíos y no se han inventado precios ni enlaces. **Advertencia:** si ya habías añadido productos, no sobrescribas `data/products.json` con el archivo vacío del ZIP; conserva el existente.

El texto y el botón que aparecen dentro del banner son parte de la imagen, no texto editable. El banner completo es clicable y lleva al catálogo. En móvil se escala para conservarlo completo, por lo que sus letras pueden verse pequeñas. El panel de Pages CMS todavía requiere completar su configuración.
