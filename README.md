# CNgirl

1. Sube **los archivos que hay dentro de este ZIP** a la raíz del repositorio `cngirl` (no subas el ZIP sin descomprimir).
2. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Tu dirección será `https://TU-USUARIO.github.io/cngirl/`.
4. Para el panel, abre https://pagescms.org/ y conecta GitHub. Selecciona el repositorio `cngirl` y la colección Productos.
5. Introduce nombre, marca, categoría, precio, foto, URL y fecha. Guarda y espera a que se publique.

El catálogo empieza vacío a propósito: no hay productos ficticios. El estampado leopardo es CSS; la ilustración del concepto visual todavía no está incorporada. El panel depende de Pages CMS, un servicio externo; si su interfaz o esquema ha cambiado, revisaremos la configuración juntos.
